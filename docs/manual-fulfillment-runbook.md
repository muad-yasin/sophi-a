# Sophi-A manual fulfilment runbook (historical note)

**Status: retired 2026-09-16. There is no purchase flow.**

This file once held the step-by-step runbook for hand-delivering a paid, packaged Sophi-A build
after a sale. That offer existed from 2026-09-09 until it was retired on 2026-09-16; its store
products were archived and nothing is sold today. The runbook steps were removed because they no
longer describe anything that happens.

Sophi-A is source-only under the MIT licence. See `SHOP.md` for the short history and `README.md`
for how to build and run it.
