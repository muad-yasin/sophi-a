# Sophi-A - store product copy (historical note)

**Status: retired 2026-09-16. There is no purchase flow.**

This file once held the checkout-page product name and description for a paid, packaged Sophi-A
build. That offer existed from 2026-09-09 until it was retired on 2026-09-16; its store products
were archived and nothing is sold today.

One rule from it still applies to any copy about Sophi-A: it may say in plain text that the
product runs Claude Code, but it never uses "Claude", "Claude Code" or "Anthropic" as part of
Sophi-A's own product, feature or company name or logo, and never implies Anthropic built,
endorses or partners with it (checked against Anthropic's published legal-and-compliance
guidance for Claude Code, 2026-09-09).

See `SHOP.md` for the short history.
